# Automated File Organizer
**Intern ID: CITS9867 | Codtech IT Solutions - Python Internship Task 1**

A Python script that automatically organizes messy folders into categorized subfolders based on file types.

### Features
- Organizes Images (jpg, png), Documents (pdf, docx), Videos (mp4), Music (mp3), Python Files (py)
- Auto creates folders if not exist
- Simple CLI - Just enter folder path

### How to Use
1. Run: python organizer.py
2. Enter folder path to organize

### Tech Stack
Python 3, OS Module, Shutil Module
